# Comparison

An honest map so you can pick the right tool. Every option below is good at
something; this stack is simply tuned for direct-play control on a Windows
home server with cloud-backed libraries.

| Capability | This stack | Plex | Emby | Plain Jellyfin | Infuse |
| --- | --- | --- | --- | --- | --- |
| License and cost | MIT, free, self-hosted | Freemium with paid tier | Freemium with paid Premiere | Free and open source | Paid app with free tier |
| Source availability | Fully open | Proprietary server | Proprietary with some open clients | Fully open | Proprietary |
| Setup effort | Manual, guided by installer and runbook | Guided, easiest for beginners | Guided, easy | Manual, moderate | Very easy on Apple devices |
| 4K remux direct-play | Tuned for it via external player and local proxy | Yes, depends on client and server settings | Yes, depends on client and server settings | Yes, depends on client | Excellent on Apple hardware |
| External player choice | Yes, first-class queue and resume | Limited, client dependent | Limited, client dependent | Browser and app clients, DLNA | Natively its own player |
| Cloud and debrid style libraries | Built-in mount plus sync workflow | Via add-ons and manual mounts | Via plugins and manual mounts | Via manual mounts and plugins | Via cloud integrations |
| Local proxy with metrics | Included with cache and Prometheus endpoint | Not included | Not included | Not included | Not included |
| Web control panel | Included local panel for status and playback | Hosted dashboard plus apps | Hosted dashboard plus apps | Built-in dashboard | Native app UI |
| Best fit | Tinkerers who want control and logs | Households wanting polished apps | Households wanting live TV and apps | Self-hosters wanting open basics | Apple-first viewers wanting polish |

## How to read this

- Pick this stack if you enjoy owning the full chain, reading logs, and
  squeezing out direct-play for large files.
- Pick Plex or Emby if you want the smoothest client apps with minimal setup
  and are comfortable with a paid tier for premium features.
- Pick plain Jellyfin if you want a clean open server and prefer to add your
  own pieces over time.
- Pick Infuse if your household is mostly Apple devices and you want a
  refined player with low fuss.

No option wins everywhere. If you try this stack and another tool fits you
better, that is a good outcome too.
